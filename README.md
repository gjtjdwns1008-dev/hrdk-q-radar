# HRDK Q-RADAR — AI 기반 국가기술자격 관계법령 모니터링

> **사람의 검토도, AI의 회상도 결국 표본입니다. 전수(全數)는 Q-RADAR뿐.**
> 매일 새벽, 대한민국의 제·개정 법령 전수를 자동 수집하고 AI가 **국가기술자격과의
> 관련성·우대사항**을 분석하여 대국민 사이트와 월간 브리핑으로 내보내는
> 한국산업인력공단 AI 프론티어 과제입니다.

**🔗 라이브: [자격증 법령 네비게이터](https://gjtjdwns1008-dev.github.io/hrdk-q-radar/)** — 4개 화면, 매일 4회 자동 갱신(첫 반영 06시)

## 왜 만들었나

법령은 한 해 **5,192건**('25년 실측) 바뀌지만, 담당자 수작업 검토는 그 **약 절반**만
관측할 수 있었습니다. 법이 바뀌어 특정 자격자의 채용이 의무화되어도, 정작 그 자격증을
가진 국민은 모르고 지나치는 "정보의 사각지대" — Q-RADAR는 이 번역을 기계가 매일
대신합니다: **"어떤 자격증에, 어떤 이득(의무고용·직무권한부여·인사우대·시험면제)이
생겼는지"**, 근거 조문과 현재 채용 건수까지.

## 8개월 실증 결과

| 지표 | Before | After |
|---|---|---|
| 담당자 업무 | 연 450~680시간 (분기 야근) | **일 5분 이내** (95%↑ 절감) |
| 분석 커버리지 | 연 2,723건 (수작업 관측) | **연 5,192건 전수** (약 2배) |
| '검토 필요' 대기 | 1,255건 | **170건** (−86.5%, 잔여는 정당 보류) |
| 데이터 무결성 | 누락 위험 상존 | **법령 임의 폐기 0건** |
| 신규 인프라 예산 | — | **0원** (유일한 실비: AI 사용료) |

무인 자동 전환('26. 3.) 이후 중단 없이 실운영 · 통합 대장 1,788행+ 축적(법령 1건당 24개 분석 항목)

## 라이브 화면 (4개)

| 화면 | 내용 |
|---|---|
| **법령 모니터링 총괄현황** | 날짜별 수집·검토·우대 집계 — 수치를 누르면 그날의 법령 목록·상세 분석까지, 수집 실패일은 사유와 함께 정직 표기 |
| **자격증 활용도 모니터링** | 제·개정 법령별 노동시장 활용도 분석 — 소관부처 필터·종목 칩 클릭 검색·결과 CSV |
| **자격증별 우대사항** | 종목 카드 → 우대 법령·성격·근거 조문 — 직능연 유형화 승계 5종 분류 |
| **월간 이슈브리핑** | 자동 생성 + 담당자 검토 후 게시되는 심층 해설 (게시 = 검토자의 커밋) |

모든 화면 상단에 **AI 분석물 고지 배너**, 총괄현황에 **신뢰 카운터**(누적 검토·우대 축적·임의 폐기 0건) 상시 노출.

## 통제된 AI — 이 저장소의 진짜 주제

- **환각 차단**: 종목 사전(541종) 전량 대조 + 옛 명칭 변환(252건) — "이 목록 안에서만"
- **과잉추론 차단**: '행정규제의 직접적 명시' 판정 규칙 (700여 건 오판 사건의 유산)
- **자기 해명 검증**: AI가 낸 검토 사유 속 인용을 원문 대조 — 판단도, 설명도 검증 대상
- **회귀 검증**: 기준일자(약 1,000건) 전량 재분석을 통과해야 프롬프트 개정 반영
- **HITL 3단**: 판정('검토 필요' 정직 신고) → 발행(브리핑 검토) → 게시(커밋 = 승인)
- **무손실 원칙**: 어떤 실패에도 법령을 조용히 버리지 않음 — 실패는 화면에 정직하게

프롬프트 개정 이력 V1~V26.4+, 장애 대응은 "관측 → 반증 → 확정 → 방어"의 수사 방법론으로
전 과정 문서화 (예: 별표 705개 대량 수집 마비 → 연결 재사용으로 수 시간 → 194초).
