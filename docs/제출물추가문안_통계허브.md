### 방문 통계 허브 (stats)
Q-PAGE·Q-RADAR 공개 화면의 방문 수를 쿠키·개인식별 없이 집계(GoatCounter)하고, 일별 원장을 저장소에 적층해 전 기간 이력을 자체 보존합니다.
- 구성: `.github/workflows/stats-collect.yml`(매일 09:05 KST 1회) · `tools/build_stats.py` · `stats-ledger/`(일별 원장 JSON) · `stats-site/index.html`(통합 관제판 — Q-PAGE가 /stats로 서빙)
- 열쇠: GitHub Secrets `GOATCOUNTER_TOKEN` 1개(통계 읽기 전용)
- 분석 파이프라인과 완전 분리: 별도 워크플로이며 커밋 메시지 [skip ci]로 어떤 빌드도 유발하지 않고, pipeline/·core/·navigator/ 등 기존 파일은 건드리지 않습니다.
- 심사 참고: 이 워크플로가 매일 1회 `chore: 방문통계 …` 커밋을 만듭니다. 구동 재현(경로 ②·③)과 무관하며, 저장소 대조 시 `stats-ledger/`·`stats-site/`는 제외하고 보시면 됩니다.
- 열쇠 없이 화면만 보기: `python tools/build_stats.py <Q-PAGE_HTML> stats-site --demo`
