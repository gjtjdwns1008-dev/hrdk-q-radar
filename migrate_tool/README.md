# migrate_tool/ — 정비·보완 도구 모음

운영 파이프라인(`pipeline/`·`core/`)과 **분리된** 도구들입니다. 대장(구글 시트)의 과거 데이터를 이관·백필·교정하거나,
운영 결과를 다른 채널로 내보냅니다. **`pref_export`를 제외하면 전부 담당자 PC에서 손으로 실행**하며, GitHub Actions는 부르지 않습니다.

## 공통 규칙

- **▶ 버튼으로 실행** — 모든 도구는 VS Code의 Python ▶(인자 없음)으로 돌아가야 하고, 필요한 선택은 화면에서 묻습니다.
- **열쇠는 한 곳** — 시트 주소·서비스계정·API 키는 레포 루트 `local_run/local.env`·`local_run/gcp-key.json`에서 읽습니다(변수 이름은 GitHub Secrets와 동일). 이 폴더 안에는 `.env`·키 파일을 두지 않습니다('26. 10. 13. 열쇠 단일화). 견본은 `reanalyze_ledger/env.example`.
- **쓰기 전 미리보기·백업** — 시트에 쓰는 도구는 미리보기를 먼저 보여 주고, 기록 전에 백업 탭을 만들며, 기록 후 다시 읽어 검산합니다.
- **국내 IP에서** — 법제처 API는 해외 IP를 간헐적으로 차단합니다.
- 산출물(`work/`, 캐시, 대조 엑셀)은 커밋하지 않습니다(`.gitignore`).

## 왜 이 폴더가 있나

Q-RADAR의 분석은 AI가 하지만, **규칙은 쌓인 오답에서 재정립**됩니다. 규칙이 바뀌면 과거 분석분도 같은 기준으로 다시 봐야 하고,
그 작업은 사람이 미리보기를 보고 승인하는 로컬 도구가 맡습니다. 운영 배치(매일 새벽)는 사람 승인 없이 기록되므로, 거기서 틀린 것은
프롬프트·코드에 규칙을 박아 원천적으로 줄이고(`pipeline/brain.py` 방어망 R1~R7), 여기서는 그 규칙으로 과거분을 한 번에 따라잡습니다.
