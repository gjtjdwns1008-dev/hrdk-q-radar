# Q-RADAR 대장 재분석 도구 (`migrate_tool/reanalyze_ledger/`) — 2026-09-16 신설

개정 프롬프트(brain.py)로 대장의 지정 행을 **다시 분석하고, 결과를 엑셀로 먼저 받아 사람이 승인한 행만** 시트에 반영합니다.
분석 로직은 여기 없고 core(scraper·brain·certs)를 그대로 부릅니다. 시트에 쓰는 코드는 `apply.py` 한 곳뿐입니다.

## 준비 (1회)
1. `env.example` → `.env` 복사 후 값 채우기, 같은 폴더에 `gcp-key.json` (둘 다 깃허브 금지 — `.gitignore` 포함)
2. 로컬 백필 때 쓰던 파이썬 환경(hrdk-law-core 설치됨)에서 실행. 법제처 차단을 피하려면 **국내 IP**에서.

## 가장 쉬운 방법 — `start.py` 를 ▶ 버튼으로 실행
메뉴 [1] 대상 선정 → [2] 재분석(건수는 화면에서 질문, 엔터=전량) → [3] 시트 반영(미리보기 후 '반영' 입력 시에만 기록). 명령줄 인자 필요 없음.

## 3단계 (명령줄로 할 때)
| 단계 | 명령 | 하는 일 | 시트 |
|---|---|---|---|
| 1 scan | `python scan.py --targets QRADAR_이상건_목록.xlsx` | 대상 선정 → `work/대상목록_날짜.xlsx` | 읽기만 |
| 2 run | `python run.py --targets work/대상목록_날짜.xlsx` | 시행일자 판본 원문 재수집 → 개정 프롬프트 분석 → `work/재분석_대조_날짜.xlsx` (구/신 값 나란히, 승인 열) | 읽기만 |
| 검토 | 엑셀에서 바뀐 칸(색 표시) 확인 → 승인 열에 O | — | — |
| 3 apply | `python apply.py --file work/재분석_대조_날짜.xlsx` (미리보기) → `--commit` | 승인 O 행만 MST_ID 대조 후 기록. 백업 탭 먼저 | **쓰기** |

`--local 대장.xlsx` 를 주면 구글 시트 대신 로컬 파일을 읽습니다(오프라인 검토·테스트). `--all` 은 대장 전체(후속 전수 회귀검증용).

## 안전장치
- 고정 키 4열(MST_ID·시행일자·소관부처·법령명)은 절대 덮어쓰지 않음. 분석 산출 20열만 갱신.
- 승인 빈칸 = 미반영(기본). 변경 없는 행은 반영할 것이 없음.
- apply 는 MST_ID 로 행을 다시 찾아 쓰므로(행 번호 신뢰 안 함) 시트가 중간에 정렬돼도 안전. 대장에 MST_ID 중복이 있으면 scan 이 경고하고 apply 는 중단.
- 원문·분석 결과는 `work/cache/` 에 캐시 → 중단 후 이어하기, 재실행 시 법제처·AI 재호출 없음.
